# Definition of Done

A SubSeaRenamer release is done only when:

- the UI can create a complete operation plan;
- the operator sees and confirms every destination name before execution;
- the native core executes copies without modifying originals;
- every completed copy passes the configured validation;
- conflicts and failures stop safely;
- restart/recovery does not create false completion;
- logs and reports identify every item;
- the Windows Portable package works offline;
- the Windows installer works on a clean machine;
- the release checklist and test matrix pass;
- no known critical integrity defect remains.

A visually complete preview is not sufficient for release.
