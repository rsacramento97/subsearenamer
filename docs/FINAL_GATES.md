# Final gates

The project is ready for production only after all of these are true:

- native Windows integration complete;
- source videos remain unchanged in byte/hash comparison;
- no overwrite occurs;
- interruptions leave no false-success destination;
- recovery is validated;
- Portable works offline;
- installer works on a clean Windows machine;
- large-file and batch tests pass;
- operator QA sign-off is recorded.
