# SubSeaRenamer

Aplicativo profissional para organização e renomeação segura de vídeos de inspeção submarina com ROV.

## Objetivo

Preservar integralmente os vídeos originais e criar cópias renomeadas em uma nova pasta.

O projeto terá uma interface de preview desenvolvida no Lovable e será posteriormente preparado para distribuição como aplicativo Windows Portable e instalável.
